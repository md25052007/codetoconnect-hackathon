AI/NLP Financial Risk Engine: architecture and data flow

Unstructured text in, structured risk signals out, consumed by two downstream modules. Everything runs locally in Python.

1 · Sources

News feedReddit r/worldnews top-25 headlines/day20,485 headlines · 2014–2016
Social mediaTweets mentioning the 20 index stocks (StockNet)59,777 tweets · 2014–2016
Live connectorsGoogle News RSS · Reddit r/stocks, r/investing, r/wallstreetbetspython main.py live
Market dataDaily adjusted prices (20 stocks + DJIA)back-test & validation only
➜

2 · Ingestion

Source adaptersEach source yields a common Document (id, source, channel, timestamp, text, tickers, meta)
Chronological mergeheap-merge of all sources into one time-ordered stream
Replay / real timeaccelerated replay of history, or live polling; batch of 512 docs to the engine
Text cleaningURLs, @mentions, RT prefixes, HTML entities; cashtags kept for linking
➜
3 · NLP Risk Engine (the core deliverable)
Entity linkingcashtags → company aliases → sector keywords (oil → XOM, CVX) → MARKET for macro / geopolitical news; spam lists damped
Sentiment −1 … +1TF-IDF + logistic regression (trained on 14k labelled finance sentences & tweets) ⊕ VADER + finance lexicon; domain-aware weights; neutral dead-zone → 0
Event classificationweighted domain rules ⊕ weak-supervised classifier (rules label 80k texts → model learns context); 7 classes + Other
Impact score 1 … 10severity(event) × intensity(|sentiment|) × credibility(source, followers) × reach(systemic?) + urgency + magnitude + popularity, every factor returned for explainability
Output contract (one signal per document × entity): { "entity": "MARKET", "entity_type": "market", "sentiment": -0.80, "sentiment_label": "negative", "event_type": "Geopolitical", "event_confidence": 0.81, "impact": 10.0, "source": "news", "timestamp": "...", "explain": { "severity": 0.8, "reach": 1.15, ... } }
➜

4 · Signal store & consumers

Signal storesignals.jsonl.gz (101k doc-level signals) · SQLite · daily per-entity aggregates (impact-weighted, volume-shrunk score, buzz)
FastAPI/signals · /analyze · /stream (SSE) · /modules/index/* · /modules/stress/*
Module A · Index rebalancerEWMA sentiment → relative z-score → exp tilt, 1–12 % caps, 20 % turnover limit; back-test vs equal weight
Module B · Stress testertrigger: negative market-level event, impact > threshold (+ corroboration) → scaled shock scenario → bonds, loans, equity, IRS, CDS, FX P&L
Streamlit dashboardlive analysis & replay · weights over time · before/after stress · model quality
Offline trainingFinancial PhraseBank (4.8k) + Twitter Financial News Sentiment (9.5k) → sentiment model; rule-labelled corpus → event model (python main.py train)
Evaluationheld-out test sets · 200 hand-labelled headlines/tweets · impact vs realised |returns| (python main.py evaluate)
Optional back-endsFinBERT sentiment (RISK_ENGINE_FINBERT=1) and BART zero-shot events (RISK_ENGINE_ZEROSHOT=1) plug into the same interfaces
All data is public (StockNet MIT, Reddit WorldNews CC BY-NC-SA, Financial PhraseBank CC BY-NC-SA) or synthetic (banking portfolio). No proprietary or client data.
